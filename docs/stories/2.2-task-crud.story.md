# Story 2.2: Task CRUD

**Status:** Ready for Review

**As a** user,
**I want** to create, read, update, and delete tasks within a project,
**so that** I can manage my work.

## Acceptance Criteria
1.  A user can create a task with a title, description, priority, and due date.
2.  A user can view the details of a single task.
3.  A user can update any attribute of a task.
4.  A user can delete a task.

## Dev Notes

### Previous Story Insights
Story 2.1 (Project CRUD) is assumed to be complete, providing the ability to manage projects.

### Data Models
*   **Task:** `{ id: string; title: string; description: string; priority: 'LOW' | 'MEDIUM' | 'HIGH'; status: 'TO_DO' | 'IN_PROGRESS' | 'DONE'; dueDate: string; assignee?: User; }` [Source: architecture/data-models.md]

### API Specifications
*   **Create Task:** `POST /api/projects/{projectId}/tasks` with `{ title: string, description: string, priority: string, dueDate: string }`.
*   **Get Task by ID:** `GET /api/tasks/{taskId}`
*   **Update Task:** `PUT /api/tasks/{taskId}` with the updated task attributes.
*   **Delete Task:** `DELETE /api/tasks/{taskId}`.

### Component Specifications
*   **Frontend:** Task creation form (modal/page), Task detail view, Task edit form.

### File Locations
*   **Frontend:** `apps/web/src/components/tasks/`
*   **Backend:** `apps/api/src/main/java/com/taskflow/task/controller/TaskController.java`, `apps/api/src/main/java/com/taskflow/task/service/TaskService.java`, `apps/api/src/main/java/com/taskflow/task/model/Task.java`

### Testing Requirements
*   **Backend:** Unit tests for task service, integration tests for task CRUD endpoints. [Source: architecture/tech-stack.md - Backend Testing: JUnit]
*   **Frontend:** Unit tests for task components, integration tests for task CRUD functionality.

### Technical Constraints
*   Tasks should be associated with a project.
