# Story 4.1: Export Reports

**Status:** Ready for Review

**As a** manager,
**I want** to export a report of tasks for a project,
**so that** I can analyze progress and share it with stakeholders.

## Acceptance Criteria

1.  A user can export a list of tasks for a given project.
2.  The export format can be either CSV or PDF.
3.  The report includes task title, description, assignee, priority, due date, and status.

## Dev Notes

### Previous Story Insights

Epic 3 (Interactive Kanban Board & Collaboration) is assumed to be complete, providing task management and collaboration features.

### Data Models

- **Task:** `{ id: string; title: string; description: string; assignee?: User; priority: string; dueDate: string; status: string; }` [Source: architecture/data-models.md]

### API Specifications

- **Export Report:** `GET /api/projects/{projectId}/export?format={csv|pdf}` to trigger report generation and download.

### Component Specifications

- **Frontend:** Export button, format selection (CSV/PDF).

### File Locations

- **Frontend:** `apps/web/src/components/reports/ExportButton.tsx`
- **Backend:** `apps/api/src/main/java/com/taskflow.report/controller/ReportController.java`, `apps/api/src/main/java/com/taskflow.report/service/ReportService.java`

### Testing Requirements

- **Backend:** Unit tests for report generation logic, integration tests for export API endpoint.
- **Frontend:** Unit tests for export components, integration tests for triggering download.

### Technical Constraints

- **Backend:** Libraries for CSV and PDF generation (e.g., Apache POI for CSV, iText/OpenPDF for PDF).

- [x] **Frontend: Create Export Button:** Implement a button on the project view to trigger report export. (AC: 1)
- [x] **Frontend: Implement Format Selection:** Allow users to choose between CSV and PDF formats. (AC: 2)
