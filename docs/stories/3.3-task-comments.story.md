# Story 3.3: Task Comments

**Status:** Ready for Review

**As a** user,
**I want** to add comments to a task,
**so that** I can collaborate with my team.

## Acceptance Criteria
1.  A user can add a text comment to a task.
2.  All comments for a task are displayed in chronological order.
3.  The system sends a notification to the task assignee when a new comment is added.

## Dev Notes

### Previous Story Insights
Story 3.2 (Drag-and-Drop Tasks) is assumed to be complete, providing an interactive Kanban board.

### Data Models
*   **Task:** The `Task` model should be updated to include a list of comments.
*   **Comment:** A new `Comment` model will be needed with `{ id: string; content: string; author: User; createdAt: string; }`.

### API Specifications
*   **Add Comment:** `POST /api/tasks/{taskId}/comments` with `{ content: string }`.

### Component Specifications
*   **Frontend:** Comment input form, Comment list component.

### File Locations
*   **Frontend:** `apps/web/src/components/comments/`
*   **Backend:** `apps/api/src/main/java/com/taskflow/comment/controller/CommentController.java`, `apps/api/src/main/java/com/taskflow/comment/service/CommentService.java`, `apps/api/src/main/java/com/taskflow/comment/model/Comment.java`

### Testing Requirements
*   **Backend:** Unit tests for comment service, integration tests for the add comment endpoint.
*   **Frontend:** Unit tests for comment components, integration tests for adding and displaying comments.

### Technical Constraints
*   Notifications are a "stretch goal" for this story and can be implemented as a simple in-app notification for now.

- [x] **Backend: Implement Comment Service:** Create a service for adding comments to tasks.
- [x] **Backend: Implement Comment Controller:** Create `POST /api/tasks/{taskId}/comments` endpoint.
- [x] **Frontend: Create Comment Input Form:** Implement a form for adding new comments to a task. (AC: 1)
- [x] **Frontend: Create Comment List Component:** Implement a component to display a list of comments in chronological order. (AC: 2)
- [x] **Frontend: Integrate Comment API:** Connect the comment form to the backend API.
- [x] **Backend: Implement Basic Notifications:** When a comment is added, create a simple notification for the task assignee. (AC: 3)
