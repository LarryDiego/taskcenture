# Story 2.3: Dashboard

**Status:** Ready for Review

**As a** user,
**I want** to see a dashboard with a summary of my projects,
**so that** I can quickly understand the overall progress.

## Acceptance Criteria
1.  The dashboard displays a list of projects.
2.  For each project, a completion percentage is shown (based on the number of "Done" tasks).
3.  The dashboard includes summary charts of project progress.

## Dev Notes

### Previous Story Insights
Story 2.2 (Task CRUD) is assumed to be complete, providing the ability to manage tasks within projects.

### Data Models
*   **Project:** `{ id: string; name: string; description: string; tasks: Task[]; }` [Source: architecture/data-models.md]
*   **Task:** `{ id: string; status: 'TO_DO' | 'IN_PROGRESS' | 'DONE'; }` (for calculating completion percentage) [Source: architecture/data-models.md]

### API Specifications
*   **Get All Projects:** `GET /api/projects` [Source: architecture/api-specification.md]

### Component Specifications
*   **Frontend:** Dashboard component, Project Card component, Chart component (for summary charts).

### File Locations
*   **Frontend:** `apps/web/src/pages/Dashboard.tsx`, `apps/web/src/components/dashboard/ProjectCard.tsx`, `apps/web/src/components/charts/ProjectProgressChart.tsx`

### Testing Requirements
*   **Frontend:** Unit tests for dashboard components, integration tests to verify data display from API.

### Technical Constraints
*   The dashboard should be responsive.
