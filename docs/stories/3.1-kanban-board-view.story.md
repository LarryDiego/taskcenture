# Story 3.1: Kanban Board View

**Status:** Ready for Review

**As a** user,
**I want** to view my tasks on a Kanban board,
**so that** I can visualize my workflow.

## Acceptance Criteria
1.  A Kanban board is displayed for each project.
2.  The board has three columns: "To Do", "In Progress", and "Done".
3.  Tasks are displayed as cards in the appropriate column based on their status.

## Dev Notes

### Previous Story Insights
Epic 2 (Core Task & Project Management) is assumed to be complete, providing project and task CRUD functionality.

### Data Models
*   **Task:** `{ id: string; title: string; status: 'TO_DO' | 'IN_PROGRESS' | 'DONE'; }` [Source: architecture/data-models.md]

### API Specifications
*   **Get All Tasks for a Project:** `GET /api/projects/{projectId}/tasks` [Source: architecture/api-specification.md]

### Component Specifications
*   **Frontend:** Kanban Board component, Kanban Column component, Task Card component.

### File Locations

### Testing Requirements

### Technical Constraints
