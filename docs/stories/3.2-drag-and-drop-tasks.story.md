# Story 3.2: Drag-and-Drop Tasks

**Status:** Ready for Review

**As a** user,
**I want** to drag and drop tasks between columns on the Kanban board,
**so that** I can easily update their status.

## Acceptance Criteria
1.  A task card can be dragged from one column to another.
2.  Dropping a task in a new column updates the task's status in the backend.
3.  The UI updates to reflect the new task status.

## Dev Notes

### Previous Story Insights
Story 3.1 (Kanban Board View) is assumed to be complete, providing the visual Kanban board with tasks displayed in columns.

### Data Models
*   **Task:** `{ id: string; status: 'TO_DO' | 'IN_PROGRESS' | 'DONE'; }` [Source: architecture/data-models.md]

### API Specifications
*   **Update Task Status:** `PUT /api/tasks/{taskId}/status` with `{ status: string }` or `PUT /api/tasks/{taskId}` with `{ status: string }` as part of the task object.

### Component Specifications
*   **Frontend:** Draggable Task Card component, Droppable Kanban Column component.

### File Locations
*   **Frontend:** `apps/web/src/components/kanban/TaskCard.tsx`, `apps/web/src/components/kanban/KanbanColumn.tsx`
*   **Backend:** `apps/api/src/main/java/com/taskflow.task/controller/TaskController.java`

### Testing Requirements
*   **Frontend:** Unit tests for drag-and-drop functionality, integration tests to verify UI updates and API calls.
*   **Backend:** Integration tests for the task status update API endpoint.

### Technical Constraints
*   Frontend drag-and-drop library (e.g., `react-beautiful-dnd` or `dnd-kit`).

## Tasks / Subtasks

1.  **Frontend: Implement Drag-and-Drop:** Integrate a drag-and-drop library into the Kanban board. (AC: 1)
2.  **Frontend: Update Task Status Locally:** Implement logic to update the task's status in the frontend state when dropped into a new column. (AC: 3)
3.  **Frontend: Call Backend API:** Make an API call to update the task's status in the backend. (AC: 2)
4.  **Backend: Implement Task Status Update Endpoint:** Create or modify an API endpoint to update a task's status.
5.  **Backend: Write Integration Tests:** For the task status update endpoint.
6.  **Frontend: Write Unit Tests:** For drag-and-drop components.
7.  **Frontend: Write Integration Tests:** To verify the full drag-and-drop workflow.
